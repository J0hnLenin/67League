# 6-7 Лига

Студенческая онлайн-лига по игре Го. Сезоны, дивизионы, клубы, бейджи и внутриигровая валюта.

## Что это

**6-7 Лига** — самостоятельный проект для студентов, преподавателей и выпускников вузов, которые играют в Го. Название — отсылка к мему «6-7».

Формат: сезонная лига с дивизионами, клубами и геймификацией. Играть можно на OGS, KGS, Fox или оффлайн.

## Как это работает

- **Сезон** — 1 месяц.
- **Дивизионы** — S, A, B. Повышение и понижение по итогам сезона.
- **Партии** — игроки сами приглашают друг друга. Победа даёт LP и камни.
- **Клубы** — игроки объединяются по городу, вузу или интересам. Клубный зачёт — сумма LP участников.
- **Бейджи** — достижения за игру, стрики, активность. Открывают титулы.
- **Титулы** — один активный у ника, все бейджи на странице игрока.
- **Супертитул «Чемпион 67»** — лучший игрок лучшего клуба сезона.

## Валюты

- **LP** — соревновательный рейтинг. Не тратится.
- **Камни** — валюта для косметики и удобств. Не даёт игрового преимущества.

## Стек

- Frontend: Next.js / React
- Backend: Supabase / Postgres
- Auth: логин-пароль, хеши
- Хранилище: S3 для SGF и изображений
- Уведомления: email (позже Telegram, ВК)
