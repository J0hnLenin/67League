# 6-7 Лига: Основные сущности (Примерный набросок)

## Игрок (Player)

| Поле | Тип | Описание |
|---|---|---|
| id | число | Уникальный идентификатор |
| имя | строка | Имя и фамилия |
| ник_кгс | строка, опционально | Ник на KGS |
| ник_огс | строка, опционально | Ник на OGS |
| ник_фокс | строка, опционально | Ник на Fox |
| рфг_id | строка, авто | ID на сайте РФГ, заполняется автоматически |
| спутник_id | строка, авто | ID на сайте Спутник, заполняется автоматически |
| город | строка | Город игрока |
| дата_регистрации | дата | Когда зарегистрировался |
| клуб_id | ссылка | Клуб, за который играет |
| валюта | число | Игровая валюта (камни) |
| кубки | число | Престижная валюта (кубки) |
| рейтинг | число | Текущий рейтинг (если есть) |
| дивизион_id | ссылка | Текущий дивизион |
| бейджи | список | Все полученные бейджи |
| титул | строка | Выбранный титул для отображения у ника |
| супертитул | строка, опционально | Чемпион 67, действует один сезон |
| статус | enum | активен / в запасе / исключён |
| роль | enum | игрок / капитан / админ / судья |

## Клуб (Club)

| Поле | Тип | Описание |
|---|---|---|
| id | число | Уникальный идентификатор |
| имя | строка | Название клуба |
| город | строка | Город клуба |
| дата_основания | дата | Когда создан |
| капитан_id | ссылка | Игрок-капитан |
| состав | список | Игроки клуба |
| бейджи | список | Клубные бейджи |
| очки_сезона | число | Клубный зачёт текущего сезона |
| история_сезонов | список | Результаты по сезонам |
| статус | enum | активен / распущен |

## Сезон (Season)

| Поле | Тип | Описание |
|---|---|---|
| id | число | Уникальный идентификатор |
| номер | число | Номер сезона (1, 2, 3…) |
| название | строка | Например «Сезон 67» |
| дата_начала | дата | Начало сезона |
| дата_конца | дата | Конец сезона |
| статус | enum | анонс / идёт / завершён |
| дивизионы | список | Все дивизионы сезона |
| лучший_клуб | ссылка | Клуб, занявший 1 место |
| чемпион_67 | ссылка | Игрок, получивший супертитул |

## Дивизион (Division)

| Поле | Тип | Описание |
|---|---|---|
| id | число | Уникальный идентификатор |
| сезон_id | ссылка | К какому сезону относится |
| уровень | enum | S / A / B |
| группа | строка | Буква или номер группы внутри уровня |
| состав | список | Игроки дивизиона |
| таблица | список | Позиции, LP, процент побед |
| ротация_вверх | число | Сколько повышается |
| ротация_вниз | число | Сколько понижается |
| статус | enum | идёт / завершён |

## Партия (Match)

| Поле | Тип | Описание |
|---|---|---|
| id | число | Уникальный идентификатор |
| сезон_id | ссылка | В каком сезоне сыграна |
| дивизион_id | ссылка | В каком дивизионе |
| игрок_1_id | ссылка | Игрок 1 |
| игрок_2_id | ссылка | Игрок 2 |
| дата | дата опционально | Когда сыграна |
| формат | enum | OGS / KGS / Fox / оффлайн |
| победитель_id | ссылка | Кто победил |
| разница_очков | число, опционально | С каким отрывом |
| sgf | файл опционально | Запись партии |
| ссылка | строка, опционально | Ссылка на партию на сервере |
| статус | enum | ожидает подтверждения / подтверждена / завершена |
| подтвердил_id | ссылка опционально | Кто подтвердил результат |
| lp_чёрный | число | Очки, начисленные чёрному |
| lp_белый | число | Очки, начисленные белому |
| комментарий | строка, опционально | Заметка от игрока или судьи |
