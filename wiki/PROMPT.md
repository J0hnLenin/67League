# КОНТЕКСТ ПРОЕКТА

«6-7 Лига» — самостоятельный проект для студентов, преподавателей и выпускников вузов, которые играют в Го.  
Название — отсылка к мему «6-7».

Формат:
- Сезон = 1 месяц.
- Дивизионы S, A, B. В будущем количество может меняться.
- Группа и дивизион — одно и то же. Везде используем термин «дивизион».
- Играть можно на OGS, KGS, Fox или оффлайн.
- Клубы: город, вуз, сообщество.
- Клубный зачёт: сумма LP активных участников.
- LP — соревновательный рейтинг, не тратится.
- Камни — валюта для косметики и удобств, не даёт игрового преимущества.
- Бейджи открывают титулы.
- Супертитул «Чемпион 67» — лучший игрок лучшего клуба сезона.

# ПОРЯДОК РАБОТЫ

## Этап 1. Бизнес-логика

Опиши:
- глоссарий;
- жизненные циклы игрока, сезона, партии;
- use cases;
- инварианты;
- формулы LP, камней, стриков, клубного зачёта, ротации;
- список настроек сезона и сайта;
- события и уведомления.

Ключевые правила:

### Валюты
- LP — соревновательный рейтинг, не тратится.
- Камни — валюта для покупок.

### Игрок
- Регистрация: имя, email, пароль, город, ники KGS/OGS/Fox, РФГ, клуб.
- Рейтинг РФГ подтягивается автоматически. Если нет — 0.
- Если рейтинг 0 — в самый низкий дивизион.
- Статусы: `active`, `inactive`, `banned`.
- `inactive` — не сыграл меньше `p` партий по итогу сезона. Может вернуться кнопкой «Вступить в сезон».
- `banned` — только админ. Ничего нельзя.

### Клуб
- Название уникально.
- Создатель автоматически участник.
- Бейдж 🏛️ Основание.
- При 10 участниках — 👥 Полный состав.
- Игрок только в одном клубе.
- Переход без ограничений.
- 0 участников — архив.

### Сезон
Статусы: `announced`, `registration`, `active`, `closing`, `finished`, `archived`.
- `announced` — регистрация, партии нельзя.
- `registration` — регистрация, партии нельзя.
- `active` — регистрация налету, партии можно.
- `closing` — приём партий закрыт, идёт подтверждение.
- `finished` — подсчёт, ротации, призы.
- `archived` — только чтение.
Переходы делает админ вручную.

### Дивизион
- Код S/A/B.
- Алиас — полное название.
- Диапазон рейтинга.
- Порядок.
- Ротация вверх/вниз.
- Группа = дивизион.

### Партия
Статусы: `proposed`, `accepted`, `playing`, `pending_confirmation`, `confirmed`, `cancelled`.
- Вызов создаёт игрок А.
- Игрок Б принимает или отклоняет.
- Принятие — 3 дня.
- Отмена — любой игрок в любой момент, если прошло меньше `match_cancel_days`. Админ — всегда.
- Играть только с игроком из своего дивизиона.
- Максимум `n` партий с одним соперником за сезон.
- Результат вносит победитель.
- Подтверждает соперник.
- Внесение и подтверждение — до конца сезона.
- Автоподтверждения нет.
- Если соперник молчит — партия не учитывается.

### LP и камни
LP:
- Победа: +`lp_win`.
- Поражение: +`lp_loss`.
- Снятие стрика 3: +`streak_bonus_3`.
- Снятие стрика 5: +`streak_bonus_5`.
- Снятие стрика 6/7: +`streak_bonus_67`.

Камни:
- Победа: +`stones_win`.
- Поражение: +`stones_loss`.
- Каждая партия сверх `t`: +0.5.
- Снятие стрика: как выше.
- Клуб в топ-1: +`stones_club_top1` каждому активному.
- Супертитул: +`stones_super_title`.
- Максимум `n` партий с одним соперником в зачёт.
- Все транзакции — в `StoneTransaction`.

LP начисляется при `confirmed`.

### Стрики
- Внутри сезона.
- Только победы подряд.
- Ничьих нет.
- При победе: `streak_current += 1`, обновить `streak_max`.
- При поражении: `streak_current = 0`.
- Если у проигравшего был стрик >= 3, победитель получает бонус за снятие.
- Пороги: 3, 5, 6, 7.
- 6/7 — случайно 6 или 7.

### Клубный зачёт
- Сумма LP активных участников.
- Активный = сыграл >= `p` партий.
- Тайбрейк: сумма LP топ-5 игроков.

### Супертитул «Чемпион 67»
- Один игрок.
- Лучший по LP в лучшем клубе сезона.
- Тайбрейк: больше партий.
- Действует 1 сезон.
- Заменяет обычный титул.
- Пишется в `SuperTitle`.

### Ротация
- Таблица по LP.
- Тайбрейк: больше партий, затем больше побед.
- Топ-k вверх, анти-топ-k вниз.
- k1, k2, k3 — настройки.
- Меньше `p` партий — исключение, без ротации.
- S — нет повышения.
- Нижний — нет понижения.

### Бейджи и титулы
- Личные — автоматически, навсегда.
- Сезонные — автоматически по итогам, история хранится.
- Клубные — автоматически.
- Супербейдж — автоматически.
- Каждый бейдж даёт титул.
- Игрок выбирает один активный титул.
- Супертитул заменяет принудительно.
- Все бейджи видны на странице игрока.

Список бейджей:
- ⚫ Первый камень — первая партия — Каменотёс.
- 🩸 Первая кровь — первая победа — Кровожадный.
- 🦎 Камень я не дам — 3 победы — Ящер.
- 🏃 Марафонец — 10 партий за месяц — Марафонец.
- 🧱 Камнегрыз — 10 побед — Камнегрыз.
- 🔥 Огонь — стрик 3 — В огне.
- 👑 Неудержимость — стрик 5 — Неудержимый.
- 6️⃣7️⃣ Сикс-севен — 6/7 побед подряд — Сикс-Севен.
- 🏹 Охотник за головами — снял стрик — Охотник за головами.
- 🍀 Счастливчик — выиграл 0.5 очка — Счастливчик.
- 👥 Товарищеский матч — сыграл с другим клубом — Товарищ.
- 🌍 Глобалист — сыграл с другим городом — Глобалист.
- 🥇 Первое место в клубе — Клубный чемпион.
- 🥈 Второе место в клубе — Клубный вице.
- 🥉 Третье место в клубе — Клубный бронза.
- 🏆 Первое место в дивизионе — Чемпион дивизиона.
- 🥈 Второе место в дивизионе — Вице-чемпион дивизиона.
- 🥉 Третье место в дивизионе — Бронзовый призёр.
- 👑6️⃣7️⃣ Чемпион 67 — супертитул.
- 🏛️ Основание — клуб создан — Друг.
- 👥 Полный состав — 10 участников — Дружба — это чудо.

### Уведомления
- Новый вызов — сопернику.
- Вызов принят — отправителю.
- Результат внесён — сопернику.
- Результат подтверждён — вносившему.
- Бейдж получен — получателю.
Канал: email. Позже Telegram, ВК.
