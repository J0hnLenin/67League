# 6-7 Лига: Бизнес-логика

## 1. Регистрация игрока

### Условия
1. Лига создана студентами и для студентов. Мы все тут друзья. Лига создана в первую очередь для студентов, преподавателей и выпускников ВУЗов, однако принять участие может любой желающий

### Процесс
1. Игрок заполняет Google-форму: имя, город, ники KGS/OGS/Fox, email, Telegram, клуб, указывает есть ли он на сайте РФГ, указывает диапазон рейтинга
2. Система автоматически подтягивает рейтинг РФГ из сайта РФГ или спутника
3. По умолчанию у игрока 0 рейтинга, если его нет на сайте РФГ
5. Игрок выбирает клуб или создаёт свой.
6. Игрок попадает в дивизион по рейтингу.

### Ограничения
- Один игрок — один аккаунт.

## 2. Регистрация клуба

### Условия
- Название уникально
- Клуб привязан к городу и вузу (опционально).

### Процесс
1. После регистрации первого участника Клуб получает статус «Активен» и бейдж 🏛️ Основание.
2. Состав может расти. При 10 участниках клуб получает бейдж 👥 Полный состав.
3. Игрок может вступить только в один клуб.
4. Переход между клубами — без ограничений.

## 3. Старт сезона

1. Админ объявляет дату старта
2. Формируются дивизионы S / A / B по рейтингу и результатам прошлого сезона, возможны ручные корректировки
3. Внутри дивизиона — группы по n человек (настраиваемо)
4. Публикуются составы
5. Стартует приём партий
6. Все игроки получают уведомление в Telegram и на почту
7. Можно вступить налету (в активный сезон)
8. Игрок по-умолчанию вступает в сезон после регистрации

### Длительность
- Сезон = 1 месяц

## 4. Партии: правила отправки

1. Игрок А создаёт вызов: дата, формат, сервер
2. Игрок Б принимает или отклоняет.
3. Партия играется на OGS / KGS / Fox / оффлайн.
4. Один игрок с одним соперником — максимум n партий за сезон.

## 5. Партии: правила фиксации

1. Победитель вносит результат в течение n дней.
2. Указывает: победителя, SGF или ссылку (опционально), разницу очков (опционально).
3. Соперник подтверждает.


## 6. Правила перехода между дивизионами

### Ротация
- S ↔ A: k1 вверх / k1 вниз.
- A ↔ B: k2 вверх / k2 вниз.
- B ↔ C: k3 вверх / k3 вниз.
(настраивается в каждом сезоне)

### Условия повышения
- Топ-k в дивизионе по LP.
- При равном проценте — выше тот, кто сыграл больше партий.

### Условия понижения
- АнтиТоп-k-1 в дивизионе по LP

### Особые случаи
- S — нет повышения.
- D — нет понижения.
- меньше p партий - исключение, без ротации. Нужна дополнительная регистрация в сезон если вдруг игрок решил вернуться

## 7. Правила получения камней \ LP

| Действие | Камни |
|---|---|
| Победа | +3 |
| Поражение | +0 |
| Завершил стрик противника из 3 побед | +3 |
| Завершил стрик противника из 5 побед | +5 |
| Завершил стрик противника из 6 или 7 побед | +6\7 (выбирается случайно)|
| Каждая партия сверх t | +0.5 |
| Клуб в топ-1 сезона | +5 каждому активному игроку клуба |
| Обладатель супертитула | +67 |

### Ограничения
- Максимум 4 партии с одним соперником в зачёт.

## 8. Правила выдачи бейджей

### Личные бейджи
Выдаются автоматически при выполнении условия.

### Сезонные бейджи
Выдаются по итогам сезона, обновляются каждый сезон.

### Супербейдж

- Выдаётся автоматически.
- Действует один сезон.
- Показывается вместо обычного титула.

### Клубные бейджи
| Бейдж | Условие |
|---|---|
| 🏛️ Основание | Клуб создан |
| 👥 Полный состав | 10 участников |

### Логика титулов
- За каждый бейдж — свой титул.
- Игрок выбирает один титул для отображения у ника.
- Все бейджи отображаются на странице игрока.
- Секретные бейджи скрыты до получения.
- Супербейдж дает супертитул

## 9. Окончание сезона

1. За 3 дня до конца — приём партий закрывается.
2. Последние 3 дня — только подтверждение уже сыгранных партий.
3. Система считает LP, процент побед, места.
4. Формируется таблица повышений и понижений.
5. Определяется лучший клуб сезона.
6. Выдаются сезонные бейджи и супертитул.
7. Публикуется итоговый отчёт: топ игроков, топ клубов, статистика.
9. Через некоторое количество дней стартует новый сезон.

### Спорные ситуации
- Если партия не подтверждена до конца сезона — она не учитывается.

## 10. Киллер-фичи

### 1. Карта активности как в GitHub
Сетка квадратиков по дням. Цвет = количество партий. Визуально показывает, кто реально играет, а кто зашёл раз в месяц.

### 2. Стрик-баунти
Сильный игрок становится «боссом». Первый, кто его побьёт, получает награду. Это создаёт охоту и динамику.

### 3. Клубный сундук
Копится за партии всех участников клуба. Открывается раз в неделю. Внутри — камни, косметика, билеты на турниры.

### 4. Чемпион 67
Супертитул сезона. Показывается золотой рамкой у ника. Действует один сезон. За него борются все клубы.

### 6. Автоимпорт партий
Интеграция с OGS API. Партия подтягивается автоматически, результат подтверждается в один клик.
